# ifs24051-pabwer2026-reactjs

## Jalankan
```bash
bun install
bun run dev
```
Buka `http://localhost:5173`. Jangan membuka `index.html` melalui Live Server/port 5500 karena proyek ini harus diproses Vite.

## Test
```bash
bun run test
bun run test:coverage
```
Coverage ditargetkan 100% sesuai spesifikasi tugas. Pengujian mencakup helper, hooks, API, Redux, layout, components, modals, pages, App dan store.
